# NOMAD RP Core RP Commands

Pawn gamemode includes initial command guidance:
- `/help` — қазақша командалар анықтамасы
- `/stats` — қолма-қол ақша, банк балансы, аштық және шөл көрсеткіштері
- `/me` — action roleplay syntax help
- `/do` — scene/environment roleplay syntax help

Current values are in-memory demonstration values only. Database persistence, parser support for command arguments,
chat broadcasting/range checks, character authentication, and anti-abuse validation remain to be implemented.
